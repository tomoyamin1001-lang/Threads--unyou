# Threads宣伝投稿テンプレート

## ルール(条件)
- 本文では有益な情報を「チラ見せ」し、続きが気になる状態を作る
- 直接「買ってください」とは言わない
- 最後に「詳しくはコメント欄のリンクから」と自然に誘導する
- 本文にはリンクを貼らない(リンクはコメント欄に置く前提)

## 本文の型(例)
1. フック(冒頭1〜2行で興味を引く。数字・意外性・悩みへの共感など)
2. 有益な情報のチラ見せ(1〜3個。答えの一歩手前まで見せて止める)
3. 「ここから先は」「続きは」など、もっと知りたくなる一言
4. 締め:「詳しくはコメント欄のリンクから」

## 使い方
1. `note宣伝投稿/`直下に日付_投稿名でフォルダを作る
2. `01_note情報.md`に元noteの要点・目次・伝えたい価値を書く(またはヒアリングする)
3. `02_投稿本文.md`にこの型で本文を書く
4. `03_コメント欄リンク.md`にnoteのURLを控えておく
